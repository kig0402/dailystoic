# 🏛️ 데일리 필로소피 (Daily Stoic Philosophy App)

라이언 홀리데이의 베스트셀러 《데일리 필로소피(The Daily Stoic)》 스타일의 모바일 최적화 철학 명언 & 실천 해설 웹 앱입니다.

---

## ✨ 주요 특징

1. **스토아 3대 거장 + 현대 인기 철학자 큐레이션**
   - **마르쿠스 아우렐리우스**: 《명상록》의 통제의 지혜, 내면의 성채
   - **세네카**: 《인생의 짧음에 관하여》, 《도덕 서한집》의 시간과 분노 관리
   - **에픽테토스**: 《엥케이리디온》, 《담화록》의 실천적 규율과 자유
   - **프리드리히 니체**: 아모르 파티(운명애), 초인(위버멘쉬), 시련 극복
   - **아르투어 쇼펜하우어**: 《인생론》의 고독의 가치, 타인의 시선에서 벗어나기

2. **데일리 필로소피(Daily Stoic) 구성 포맷**
   - **주옥같은 원문 인용**: 고전 명작 속 핵심 원문
   - **현대적 해설 (Commentary)**: 오늘날 현대인의 불안, 번아웃, 인간관계를 다스리는 실천적 해석
   - **오늘의 실천 과제 (Daily Practice)**: 하루 동안 바로 실행해 볼 수 있는 짧은 화두

3. **모바일 스마트폰 최적화 UI**
   - **한 페이지(One-Card) 집중 뷰**: 복잡한 스크롤 없이 한눈에 들어오는 카드 레이아웃
   - **터치 제스처 지원**: 스마트폰에서 좌우 스와이프(Swipe)로 책장을 넘기듯 이전/다음 명언 탐색
   - **키보드 내비게이션**: PC 환경에서는 `←`, `→` 방향키 및 `스페이스바` 지원

4. **자유로운 탐색 기능 (하루 1개 제한 없음)**
   - **철학자별 필터**: 전체 / 마르쿠스 / 세네카 / 에픽테토스 / 니체 / 쇼펜하우어
   - **오늘의 지혜 바로가기**: 365일 연중 일수에 맞춘 오늘의 명언 즉시 확인
   - **랜덤 넘기기(🎲)**: 즉각적인 영감이 필요할 때 셔플

5. **개인화 & 편의 기능**
   - **보관함(북마크 ⭐)**: 마음에 와닿은 명언을 저장하고 언제든 다시 열람 (LocalStorage 연동)
   - **3가지 감성 테마**:
     - 📜 *양장본 파피루스* (고전 책의 따뜻한 미색)
     - 🌑 *미드나잇 다크* (깊은 밤의 흑요석 대리석 & 골드 포인트)
     - 🕊️ *새벽 미니멀* (깔끔하고 모던한 화이트/슬레이트)
   - **글자 크기 조절 (A±)**: 작게 / 보통 / 크게 3단계 가독성 최적화
   - **마음이 편안해지는 명상 차임벨 (🔔)**: 명언을 넘길 때 울리는 부드러운 싱잉볼 사운드 (Web Audio API)
   - **원클릭 공유/복사**: 명언, 해설, 실천 과제를 깔끔하게 서식화하여 클립보드로 복사

## 🚀 실행 방법

### 방법 1: 즉시 실행 (가장 간단)
- `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 브라우저에서 바로 열 수 있습니다.
- 별도의 서버나 빌드 과정 없이 100% 오프라인에서도 작동합니다.

### 방법 2: 스마트폰에서 사용하기
1. **로컬 네트워크 공유**:
   - PC에서 간단한 HTTP 서버 실행:
     ```bash
     python -m http.server 8080
     ```
   - 같은 Wi-Fi에 연결된 스마트폰 브라우저에서 `http://[PC_IP주소]:8080` 접속
2. **무료 호스팅 (추천)**:
   - 이 폴더의 파일들을 GitHub Pages, Vercel, Netlify 등에 올리면 모바일 브라우저에서 언제든 접속할 수 있으며, **'홈 화면에 추가'**를 누르면 스마트폰 앱처럼 사용할 수 있습니다.

## 📂 파일 구조
- `index.html`: 모바일 프레임 레이아웃 및 테마 스타일
- `quotes.js`: 25개의 정선된 철학 명언, 해설, 실천 과제 데이터셋
- `app.js`: 제스처, 상태 관리, 필터링, 사운드, 북마크 로직
